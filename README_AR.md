# Facture Desktop — نسخة تطوير تجريبية

برنامج Windows مكتبي بواجهة عربية وقاعدة SQLite محلية. بعد بناء EXE يعمل دون تثبيت Microsoft Excel ودون إنترنت في التشغيل اليومي.

## الوظائف الموجودة في هذه النسخة
- **إدارة عدة شركات:** عند تشغيل البرنامج تظهر شاشة لاختيار شركة أو إنشاء شركة جديدة. لكل شركة قاعدة SQLite منفصلة تمامًا؛ العملاء والفواتير والموردون والمنتجات والمخزون والتسديدات لا تختلط بين الشركات. يمكن الرجوع إلى قائمة الشركات من زر «تغيير الشركة».
- بيانات الشركات محفوظة محليًا في `%LOCALAPPDATA%\FactureDesktop`، ولا يحتاج التشغيل اليومي إلى الإنترنت أو Microsoft Excel.
- إدارة العملاء والموردين والمنتجات والمستودعات.
- إدخال فاتورة بيع أو شراء تجريبية ببند واحد.
- تسجيل تسديدات وعرض حركات المخزون الناتجة عن الفواتير.
- **استيراد** بعض البيانات الأساسية من ملف XLSM (العملاء والموردون والمنتجات والمستودعات).
- **تصدير Excel** إلى ملف XLSX بأوراق منفصلة للعملاء والموردين والمنتجات والمستودعات والفواتير وتفاصيلها والتسديدات وحركات المخزون.
- **تصدير PDF** للتقارير الموجودة في قاعدة البرنامج.
- حفظ نسخة احتياطية من قاعدة البيانات.

## بناء EXE على Windows
1. ثبّت Python 3.11 أو أحدث، مع تفعيل `Add Python to PATH`.
2. فك ضغط المشروع كاملًا إلى مجلد.
3. افتح المجلد ثم شغّل `build_windows.bat` وانتظر انتهاء التثبيت والبناء.
4. الملف الناتج يكون في `dist\\FactureDesktop.exe`.
5. قاعدة البيانات تحفظ في `%LOCALAPPDATA%\\FactureDesktop\\facture_local.db`.

## تعدد الشركات والنسخ الاحتياطية
- أنشئ شركة منفصلة لكل مؤسسة، وافتحها من قائمة الشركات.
- زر النسخة الاحتياطية داخل الشركة يحفظ قاعدة بيانات الشركة المفتوحة فقط. احفظ نسخة منفصلة لكل شركة.
- لا تحذف ملفات قاعدة البيانات يدويًا؛ فهي تحتوي على سجلات الشركة.

## بخصوص جميع أكواد VBA وPower Query
أرفقنا `ANALYSE_FICHIER_ORIGINAL_AR.md` وفيه أسماء أوراق العمل والاتصالات والاستعلامات التي أمكن كشفها من الملف. لا يمكن نقل VBA أو Power Query إلى EXE بمجرد نسخها؛ يلزم مراجعة منطقها وإعادة تنفيذه واختباره في التطبيق الجديد.

**هذه النسخة ليست بعدُ بديلًا محاسبيًا كاملًا للملف الأصلي.** الاستيراد لا ينقل كل تاريخ الفواتير والتسديدات، ولا ينفذ وحدات VBA أو تحديثات Power Query. نموذج الفاتورة حاليًا بند واحد، كما أن الطباعة النهائية والمرتجعات والضرائب والأرصدة الافتتاحية تحتاج إلى استكمال واختبارات مطابقة. احتفظ بنسخة من الملف الأصلي ولا تعتمد على نتائج مالية قبل المطابقة.

## بناء EXE عبر GitHub Actions (إذا لم يكن لديك Windows)
1. أنشئ مستودع GitHub جديدًا وارفع محتويات هذا المجلد إليه.
2. افتح تبويب **Actions** في المستودع ووافق على تفعيل Actions إذا طُلب منك ذلك.
3. اختر **Build Windows EXE** ثم **Run workflow**، أو ادفع الملفات إلى فرع `main`/`master`.
4. افتح عملية البناء الناجحة، ثم نزّل **FactureDesktop-Windows-EXE** من قسم **Artifacts**. فك ضغطه لتحصل على `FactureDesktop.exe`.

ملاحظة: ملف EXE لم يُبنَ داخل بيئة Linux الحالية؛ هذا الإعداد يطلب من خادم Windows لدى GitHub بناءه. لا ترفع بيانات محاسبية حقيقية إلى مستودع عام؛ استخدم مستودعًا خاصًا ولا تضع ملفات قواعد البيانات أو نسخ Excel الأصلية فيه.
